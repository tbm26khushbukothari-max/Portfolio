# Project card images

Each project has its own folder. Drop your image directly into the matching folder.
The folder name matches exactly what is shown on screen.

```
projects/
  loreal-paris-cannes/          → L'Oréal Paris Cannes 2025    (16:10 · 800×500px)
  galleri5-x-myntra-eors/       → Galleri5 × Myntra EORS       (16:10 · 800×500px)
  zyngai/                       → Zyngai.com                    (16:10 · 800×500px)
  rusticks/                     → RuSticks                      (16:10 · 800×500px)
  anita-dongre/                 → Anita Dongre                  (16:10 · 800×500px)
  bearcare/                     → Bearcare                      (16:10 · 800×500px)
  park-avenue/                  → Park Avenue                   (16:10 · 800×500px)
```

Name your image the same as the folder (e.g. `galleri5-x-myntra-eors.jpg`).
Max 150 KB — compress at squoosh.app before dropping in.
