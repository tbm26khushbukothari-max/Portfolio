# Case study images

Each project has its own folder. Drop your image directly into the matching folder.
The folder name matches exactly what is shown on screen.

```
case-studies/
  dabur-herbl-x-star-wars/     → Dabur Herb'l × Star Wars     (4:3 · 1200×900px)
  live-history-india/           → Live History India            (4:3 · 1200×900px)
  roos-india/                   → ROOS India                    (4:3 · 1200×900px)
  loreal-paris-cannes/          → L'Oréal Paris Cannes 2025    (4:3 · 1200×900px)
```

Name your image the same as the folder (e.g. `dabur-herbl-x-star-wars.jpg`).
Max 200 KB — compress at squoosh.app before dropping in.
