```html

  <span>

    <div class="lval">Download one-page CV</div>
  </span>
  <span class="arr">↓</span>

```

The `target="_blank"` opens it in a new tab (standard for PDF links).

## CV tips for Google / Meta roles

- Keep it strictly one page.
- Lead every bullet with a strong action verb (Led, Built, Shipped, Drove, Grew).
- Every bullet should have a number: revenue, %, audience size, timeline.
- Skills section should include: Brand Strategy, Product Marketing, GTM, AI Tools (Google AI Studio, KNIME, Tableau), Data Analysis.
- Use the same language as the JD you're applying to.
